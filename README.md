# АЛИБИ

Арканоид в атмосфере детективного дела. Классический геймплей (ракетка, мяч, кирпичи), но с миром, отсылками и атмосферой вокруг — **без раскрытия названия первоисточника** в игре.

> Неофициальный фан-проект, не связан с правообладателями.

## Что внутри

- Классический арканоид: ракетка, мяч, кирпичи, комбо, жизни.
- **Бонусы**: мультимяч, широкая ракетка, замедление, ножницы, страховка, +жизнь, захват мяча и «злая ухмылка».
- **18 уровней в 3 главах** + **босс-уровень** с Кровавым Джоном (ухмылка, HP, щит, капли).
- **Экран проигрыша** с красной ухмылкой — «ДЕЛО ЗАКРЫТО».
- Пиксель-арт целиком кодом, 3 палитры глав, прожектор, кресло, силуэт в шляпе.
- **Мобильный приоритет**: целочисленный масштаб, зона большого пальца, drag, safe-area.
- Звук через Web Audio (без файлов), сохранение рекорда, авто-пауза, PWA-иконка.

## Запуск

```bash
npm ci          # или npm install
npm run dev     # http://localhost:5173
```

Сборка:

```bash
npm run build   # typecheck + vite build → dist/
npm run preview # локальный просмотр сборки
```

Проверки:

```bash
npm run typecheck
npm run test     # Vitest: физика, уровни, бонусы
npm run levels   # валидатор levels.json
```

**Отладка уровней**: `?level=2-3` (глава-уровень, с 1) или `?level=boss`.

## Уровни

Уровни в [src/data/levels.json](src/data/levels.json): сетка из строк (до 12 колонок и 20 строк).
Символы: `.` пусто, `1..5` кирпичи, `X` неразрушимый, `legend` переопределяет типы. `boss.hp` включает босс-уровень.

## Публикация на GitHub Pages

Игра опубликована: **https://coo1off.github.io/alibi/**

Схема: `main` — исходники; ветка **`gh-pages`** — собранный сайт; в настройках репозитория
**Settings → Pages → Source: Deploy from a branch → `gh-pages` /(root)**.

Обновить сайт после изменений:

```bash
npm run deploy        # = tools/deploy-pages.sh: build → push ветки gh-pages
```

`base: './'` в [vite.config.ts](vite.config.ts) — ассеты работают и в подпапке, и на корне домена.

> Альтернатива — CI-деплой из `.github/workflows/deploy.yml` (запускается автоматически при push в `main`).
> Для первого push этого файла у токена `gh` нужен scope `workflow`:
> `gh auth refresh -s workflow`, затем `git push`. Пока файл не запушен, используйте `npm run deploy`.

## Структура

```
src/
  game/       константы, Game (физика/состояние), Ball, системы бонусов и уровней
  render/     палитры, спрайты/фигуры, фон, отрисовка поля, HUD, экраны
  input/      Pointer Events: мышь/тач, зона большого пальца, drag
  audio/      синтезированный звук
  storage/    сохранение (localStorage)
  data/       levels.json
docs/         архитектурный документ и генератор превью
```
